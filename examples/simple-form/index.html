Simple form

A small form built with user steps, an options step, a validator and a custom component rendered as a message with asMessage. Update steps let the user change an answer after the review. See Steps for more.

  • Preview
  • Code

How it works

Section titled “How it works”
  • Review reads the answers from steps and renders them in a table. asMessage: true shows it inside a bot bubble.
  • An update step like { id: 'update-age', update: 'age', trigger: 'show-review' } asks the age step again, then goes to its own trigger instead of the trigger of age.
  • steps always has the latest value of each step, so the next review shows the updated answer. Review keeps the answers of when it was rendered in useState, so the previous summaries do not change.
